# Penang Ferry Museum — Attractions Analytics Dashboard

A Streamlit dashboard for exploring visitor reviews of **Penang Ferry Museum** and its competitors across Penang.

---

## Overview

This dashboard provides:

- **PFM Analysis** — in-depth review breakdown for Penang Ferry Museum
- **Competitor Comparison** — side-by-side comparison with other Penang attractions
- **Detail Review** — full dashboard with dataset overview, review details, word clouds and map
- **Overview Places** — executive summary across all attractions

---

## Requirements

- **Python 3.9+**
- **Streamlit** ≥ 1.30
